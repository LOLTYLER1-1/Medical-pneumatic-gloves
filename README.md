# 医用气动辅助手套 (Medical Pneumatic Assistive Glove)

> 基于 **正点原子领航者 V3.9 ZYNQ7020** + **7" 800×480 触摸 LCD** 的手指被动康复训练装置
> PL(FPGA) + PS(ARM) 协同实现，不依赖外部 MCU
> 创建：2026-05-11 ｜ 最新修订：2026-08-16（台架联调打通）

---

## 项目简介

面向脑卒中后手指屈曲挛缩、神经损伤患者的手指 **被动屈伸训练** 装置：

- **摸左半屏** → 气泵加压到设定值（默认 50 kPa）自动停止，手套气室鼓胀带动手指屈曲
- **摸右半屏** → 泄气阀打开，自然回弹松手
- LCD 实时显示压力数值（`XXX.XX KPA` 大字）、状态色条、压力条
- **三层安全保护**：PL 端纯组合逻辑硬件强切（≥80 kPa 泵阀双断）、板载 KEY1 急停、
  传感器故障检测（通信失败 2~3 秒内蜂鸣 + 自动泄气锁定）
- 泄气阀选用 **常开型 (NO)**：断电自动泄压，fail-safe

### 工作原理一句话

```
摸 LCD → GT911(PS 端 EMIO 软件 IIC) → ZYNQ7020 → PCB 驱动板 → 气泵/泄气阀 → 手套气室
                                        ↑                    │
                                        └── XGZP6857D 气压传感器 (IIC 闭环反馈) ──┘
```

## 硬件连接要点（ATK MODULE U4 排针，唯一外接点）

ATK 口丝印是历史名称（UART 模块用），实际就是 4 个普通 FPGA IO：

| ATK 丝印 | FPGA 引脚 | 本项目信号 |
|---|---|---|
| LED | N15 | 气压传感器 SCL |
| KEY | G14 | 气压传感器 SDA |
| RXD | T19 | 气泵驱动 (→100R→IRLZ44N 栅极) |
| TXD | J15 | 泄气阀驱动 (→ULN2803 IN1) |
| GND | — | 共地（**12V 适配器负极必须接这里，并 2~3 根地线**） |
| VCC | — | +5V（仅传感器/上拉电源，禁带泵阀） |

板载资源（免外接）：LED0=H15 状态/心跳，KEY1=K16 急停，蜂鸣器=M14 告警，KEY_RST=N16 复位。

## 快速开始

1. 读文档：[思维导图](./01_思维导图/项目思维导图.md) → [系统原理图](./02_原理图/系统原理图.md) → [元件清单](./03_元件清单/最终元件清单_2026-07-21.md)
2. PL 重建：按 [`05_FPGA_PL/README.md`](./05_FPGA_PL/README.md) 新建 Vivado 2020.2 工程
   （器件 `xc7z020clg400-2`，需配 `clk_wiz_0` + `lcd_image_rom` 两个 IP + PS7 Block Design）
3. PS 重建：Vitis 2020.2 导入 `06_PS/system_top.xsa`，新建应用加入 `06_PS/VITIS/medical_glove_app/src/`
4. 无传感器演示：`medical_glove_top.v` 中 `SIM_PRESSURE=1`（仿真压力模型顶替传感器）；
   传感器到位后改 0 恢复真实闭环
5. 打板：`07_PCB/医用手套驱动板_gerber.zip` 直接上传嘉立创下单
