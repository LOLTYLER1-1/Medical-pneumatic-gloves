## 二、文本结构展开（树形大纲）

```
医用气动辅助手套项目
│
├─ 1. 项目目标
│   ├─ 1.1 功能需求
│   │   ├─ "+" 按钮：气泵加压 → 软体手指弯曲 → 抓握
│   │   ├─ "-" 按钮：泄压阀打开 → 软体手指回弹 → 松手
│   │   ├─ LCD 显示当前压力 (kPa)、档位、状态
│   │   └─ 触摸按键面积 ≥ 80×80 px，便于患者操作
│   ├─ 1.2 性能指标
│   │   ├─ 工作压力：0 ~ 80 kPa（柔性安全范围）
│   │   ├─ 响应时间：< 500 ms
│   │   ├─ 显示刷新率：≥ 30 FPS
│   │   └─ 压力控制精度：±2 kPa
│   └─ 1.3 适用场景
│       ├─ 脑卒中后手指屈曲挛缩康复
│       ├─ 末梢神经损伤被动训练
│       └─ 高校 / 个人实验性研究
│
├─ 2. 系统硬件架构
│   ├─ 2.1 主控：ZYNQ7020（XC7Z020CLG400-2）
│   │   ├─ PS：双核 ARM Cortex-A9，跑裸机或 FreeRTOS
│   │   └─ PL：85K 逻辑单元，跑 LCD/IIC/PWM/蜂鸣器逻辑
│   ├─ 2.2 人机界面：7" 800×480 RGB 电容触摸屏（★ 触摸芯片实为 GT911,
│   │       由 PS 端 EMIO 软件 IIC 驱动, 驱动文件沿用官方 ft5206.c 命名）
│   ├─ 2.3 气动执行 (★ 砍 V1 简化版)
│   │   ├─ 微型隔膜气泵（12V，约 1.5~3 L/min）
│   │   ├─ ~~二位三通常闭电磁阀 V1（充气控制）~~ ★ 已砍
│   │   ├─ 二位二通常开电磁阀 V2（泄气控制, 项目唯一主动阀）
│   │   ├─ 普通手套 + 气球/橡胶指套 (低成本气室)
│   │   └─ Φ4 PU 气管 + 快插接头 + 1 个三通 (并联气压传感器)
│   ├─ 2.4 反馈传感
│   │   └─ XGZP6857D 数字 IIC 气压传感器 (0~100 kPa)
│   ├─ 2.5 驱动与电路板 (★ 2026-07-30 已 PCB 化, 见 07_PCB/)
│   │   ├─ 正式 PCB: 2层板 90×68mm, 全直插(仅 AMS1117 为 SOT-223)
│   │   │   立创EDA 工程 医用手套驱动板.epro + Gerber 打板包
│   │   ├─ IRLZ44N 逻辑电平 N-MOSFET (气泵低边驱动)
│   │   ├─ ULN2803APG 达林顿阵列 (DIP-18, 只驱动 V2 阀)
│   │   ├─ 1N4007 ×2 续流二极管 (反向并联在气泵/V2)
│   │   ├─ 4.7K ×2 上拉电阻 (IIC SDA/SCL → +3.3V, PCB J2 已集成)
│   │   ├─ 栅极 100R 串联 + 100K 下拉 (上电默认关泵)
│   │   ├─ KF301-2P 接线端子 (接气泵 +/−、V2 +/−、12V 输入)
│   │   ├─ 6 芯杜邦线 (ATK MODULE U4 → 驱动板)
│   │   └─ 历史: 洞洞板原型已验证 (2026-08 台架), ESD 曾击穿 Q1 栅氧, 已换管修复
│   ├─ 2.6 电源 (★ 简化, 不需要 DC-DC 模块)
│   │   ├─ 12V/2A 开关电源 (驱动气泵和阀)
│   │   ├─ +5V 直接从 ATK MODULE Pin6 引出 (来自 ZYNQ 板)
│   │   ├─ +3.3V 直接用气压传感器模块上的板载 LDO
│   │   └─ 共地: 12V 适配器 − 必须接 ZYNQ GND (ATK Pin5)
│   └─ 2.7 板载资源 (★ 无需采购或外接)
│       ├─ LED0 (H15) - 状态指示
│       ├─ KEY1 (K16) - 急停按键
│       ├─ 蜂鸣器 (M14) - 超压/急停 2Hz 告警
│       ├─ KEY_RST (N16) - 系统复位
│       └─ 50MHz 晶振 (U18) - 主时钟
│
├─ 3. PL 端（FPGA 逻辑）开发 (★ 13 个 .v 模块已写完并上板验证)
│   ├─ 3.1 LCD 控制 (clock_reset / lcd_timing / lcd_display)
│   │   ├─ RGB 时序生成（HSYNC/VSYNC/DE/PCLK）
│   │   ├─ 800×480@60 标准时序
│   │   ├─ 中心 200×175 图片显示 (BROM IP)
│   │   └─ ★ 压力数值显示 (double-dabble BCD + 5×7 字库, "XXX.XX KPA")
│   ├─ 3.2 GT911 触摸 (★ 改由 PS 端 EMIO 软件 IIC 驱动, ft5206.c)
│   │   ├─ 根因已修复: RST 上升沿 INT 电平决定 I2C 地址 (0x5D)
│   │   ├─ PL touch_iic.v 为早期方案, 保留未用
│   │   └─ 左半屏=充气 GRIP / 右半屏=泄气 RELEASE
│   ├─ 3.3 气压传感器 (pressure_iic)
│   │   ├─ XGZP6857D IIC 读取, 地址 0x6D
│   │   ├─ ★ 已按官方规格书重写: RMW 0xA5 + sco 轮询 + 3 次单读 + 系数 1638
│   │   └─ ★ sensor_fault_o 故障检测 (NACK/总线卡低 → EMERGENCY + 蜂鸣)
│   ├─ 3.4 状态机 + PWM (glove_fsm / pwm_ctrl)
│   │   ├─ IDLE/GRIP/HOLD/RELEASE/EMERGENCY
│   │   ├─ 气泵软启动 PWM (500ms 斜坡)
│   │   └─ ★ 回差 2kPa, GRIP→HOLD 判定 >= setpoint
│   ├─ 3.5 EMIO 接口 (axi_lite_reg)
│   │   ├─ EMIO GPIO 旁路 (替代 AXI-Lite)
│   │   └─ 64 位 EMIO: setpoint 16 位 + 压力/状态/故障回读
│   ├─ 3.6 安全联锁 (safety_interlock)
│   │   └─ ≥80kPa 硬件强切 pump=V2=0 (纯组合)
│   ├─ ★ 3.7 蜂鸣器告警 (buzzer_ctrl)
│   │   ├─ 触发: safety_trigger OR ~emerg_key OR sensor_fault
│   │   └─ 输出: 2Hz 间歇方波 → 板载 M14
│   └─ ★ 3.8 仿真压力模型 (pressure_model, 2026-08-03 新增)
│       ├─ SIM_PRESSURE=1 时顶替真实传感器 (开环估算, Q8 定点)
│       ├─ 充气 12.5kPa/s, 泄气 100kPa/s, 保压泄漏 1kPa/s
│       └─ 用途: 传感器缺席时全链路演示 (08-04 气球演示即此模式)
│
├─ 4. PS 端（ARM 软件）开发
│   ├─ 4.1 框架选择
│   │   ├─ 裸机（Vitis SDK）—— 推荐入门
│   │   └─ FreeRTOS（多任务）—— 进阶
│   ├─ 4.2 任务划分
│   │   ├─ Task_UI：界面刷新、按钮检测
│   │   ├─ Task_Control：压力 PID、状态机
│   │   ├─ Task_Sensor：IIC 读传感器
│   │   └─ Task_Safety：超限保护、急停
│   ├─ 4.3 状态机 (★ 砍 V1 后简化)
│   │   ├─ IDLE：待机，泵=0, V2=0(开), 自动泄气
│   │   ├─ GRIP：抓握，泵=1, V2=1(闭), 持续打气
│   │   ├─ HOLD：保持，泵=0, V2=1(闭), 保压
│   │   ├─ RELEASE：松手，泵=0, V2=0(开), 自然回弹
│   │   └─ EMERGENCY: 强切 pump=V2=0 + ★ 蜂鸣器 2Hz 告警
│   └─ 4.4 PID 闭环（可选）
│       ├─ 输入：目标压力 (kPa)
│       ├─ 反馈：传感器压力
│       └─ 输出：PWM 占空比
│
├─ 5. 软件 / 工具链
│   ├─ Vivado 2020.2（PL 端综合实现）
│   ├─ Vitis 2020.2（PS 端应用开发）
│   ├─ PCtoLCD2002（字模/位图生成）
│   ├─ AutoCAD / SolidWorks（机械手套外形）
│   └─ KiCad / 立创 EDA（接口板原理图与 PCB）
│
├─ 6. 开发里程碑 (★ 实际完成情况, 截至 2026-08-16)
│   ├─ ✅ 选型、采购 (2026-05)
│   ├─ ✅ LCD 显示 + GT911 触摸打通 (2026-05-21, 复位时序根因修复)
│   ├─ ✅ PL 端 13 模块 + XDC + 比特流 (2026-05~08)
│   ├─ ✅ PS 端 Vitis 应用 (EMIO 触摸/状态机/DCC 日志)
│   ├─ ✅ 驱动板 PCB 设计打板 (2026-07-30, 07_PCB, 三重验证通过)
│   ├─ ✅ 台架联调 (2026-08-04, 仿真压力模式气球演示成功)
│   ├─ ⏳ 闭环恢复 (等重买 XGZP6857D 数字版, SIM_PRESSURE 改 0)
│   ├─ ⏳ 穿戴测试与安全验证
│   └─ ⏳ 文档整理、视频演示 (简易版演示 mp4 已录)
│
├─ 7. 安全与伦理（重要）
│   ├─ 7.1 压力硬上限：< 100 kPa（避免血管/神经损伤）
│   ├─ 7.2 软上限：80 kPa（safety_interlock 模块硬件强切）
│   ├─ 7.3 紧急停止：板载 KEY1 (K16) - 按下即触发蜂鸣 + 强切
│   ├─ 7.4 泄气备份阀 V2：失电常开 NO（断电自动泄压, fail-safe）
│   ├─ ★ 7.5 蜂鸣器告警：板载 M14 - 超压 OR 急停时 2Hz 间歇响
│   ├─ 7.6 续流二极管：1N4007 反向并联气泵/V2, 阴极朝 +12V
│   ├─ 7.7 共地强制: 12V 适配器 − 必须接 ZYNQ GND
│   ├─ 7.8 仅限学习实验，禁止替代医疗器械
│   └─ 7.9 任何穿戴前先用气球 / 假手测试
│
└─ 8. 风险与挑战
    ├─ 软体手指自制难度大（替代：购买成品手套）
    ├─ 气密性要求高（接头胶水密封）
    ├─ 电磁阀响应时间影响控制精度
    ├─ ZYNQ PL 资源消耗（注意 LUT、BRAM 使用率）
    └─ LCD 触摸校准（电容屏需注意干扰）
```

## 三、开发顺序建议

```
阶段 1：环境搭建
  └─ 安装 Vivado / Vitis 2020.2 → 跑通正点原子官方 LCD 触摸例程

阶段 2：单点突破（每个模块单独验证）
  ├─ LCD 显示 "+/-" 两个大按钮
  ├─ 触摸读取坐标，区分按下哪个按钮
  ├─ PL 端输出 GPIO 控制 LED 模拟气泵
  └─ PL 端 IIC 读取 XGZP6857D 气压传感器

阶段 3：硬件接入 (★ 洞洞板原型已验证 → 正式 PCB 已打板)
  ├─ 洞洞板原型: ULN2803 IC 座 + MOSFET + 1N4007 ×2 + 4.7K ×2 + 电源轨 + KF301 端子
  │   (2026-08-03/04 台架联调: 曾遇 Q1 栅氧 ESD 击穿, 换 IRLZ44N 修复;
  │    教训: 勿在布面焊接, 新 MOSFET 先焊 S 极与 100K 下拉最后焊 G 极)
  ├─ 正式 PCB: 07_PCB/医用手套驱动板.epro (立创EDA) + Gerber 打板包
  │   (2层板 90×68mm, J2 已集成 4.7K→3.3V 上拉, 免外接)
  ├─ 杜邦线接 ATK MODULE U4 → 驱动板
  ├─ 万用表测 MOSFET Drain / ULN2803 OUT1 在 grip_req=1 时是否拉低
  ├─ 接气压传感器, 用手挤进气口看屏幕压力变化
  ├─ 接气泵 + V2, 短时通断验证
  └─ 在没人穿戴情况下试运行（用气球/塑料瓶代替手）★ 2026-08-04 已成功

阶段 4：闭环控制
  ├─ 实现 "+" 持续按住 → 持续加压（限幅 80 kPa）✅ (仿真压力模式已验证)
  ├─ 实现 "-" 持续按住 → 持续泄压（直到 0 kPa）✅
  ├─ 显示压力实时数值 (LCD "XXX.XX KPA" 大字) ✅
  └─ ★ 待重买 XGZP6857D 数字版传感器后 SIM_PRESSURE 改 0 恢复真实闭环

阶段 5：穿戴测试 (⏳ 待做)
  ├─ 先用假肢 / 别人健康手测试
  ├─ 录制视频，测量响应时间 (★ 简易版演示 mp4 已录: 仿真模式气球抓握)
  └─ 收集反馈，迭代优化

阶段 6：遗留硬件问题 (2026-08-04 台架记录, 下次开机先确认)
  ├─ 地弹负尖峰: 阀切换时 T19 量到 -2.5V~-3.85V, 12V GND 与 ATK GND 需并 2~3 根地线
  ├─ ULN2803 COM(pin10) 接 12V+ 待确认 (阀线圈续流回路)
  └─ XGZP6857D 需重买 IIC 数字版 (旧传感器疑似焊接烫死; 勿买模拟版)
```
