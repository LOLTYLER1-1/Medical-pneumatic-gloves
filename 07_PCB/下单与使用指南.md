## 路线 A（最简单，推荐）：直接用 Gerber 下单

我已经把生产文件打包好了，**不用开任何软件**：

1. 浏览器打开 嘉立创下单助手（`https://www.jlc.com` → 计价/下单）。
2. 上传 **`医用手套驱动板_gerber.zip`**。
3. 等它解析完，确认参数（一般保持默认即可）：
   - 层数 **2 层**、尺寸约 **90×68mm**
   - 板厚 **1.6mm**、阻焊颜色随你（常用绿色）
   - 铜厚 **1oz**、喷锡（有铅/无铅都行）
4. 数量 5 片（最低档），提交付款。几天后快递到手。

## 路线 B：在立创EDA专业版里打开 .epro（可查看/修改）

1. 打开你电脑里的 **立创EDA专业版**。
2. 菜单 **文件 → 打开 → 项目**（或"导入"），选中 **`医用手套驱动板.epro`**。
3. 打开后你会看到**原理图**和 **PCB** 两个标签页，就是我生成的那套。
4. **建议先点一次「设计规则检查(DRC)」**确认无误（工具 → 设计规则检查）。
   - 你会看到几条"silkscreen/丝印"类的提示，那是正常的（丝印压焊盘，出厂会自动裁掉），**没有短路/未连接就是好的**。
5. 想下单：在 PCB 页 **文件 → 导出 → PCB制板文件(Gerber)**，或直接点软件里的 **"去下单"** 按钮（立创EDA和嘉立创是打通的）。

> ⚠️ 如果你在软件里看到 GND 没铺铜：那是因为铺铜在导出时按 KiCad 方式重填过。在立创EDA里若想重铺，选中底层 → 右键 → 重建所有铺铜区即可（不影响 Gerber.zip，那份已经是铺好的）。

## 收到板子后怎么焊（全直插，只有 1 个小贴片）

**焊接顺序：先矮后高。**

1. **电阻** R1/R2(4.7K)、R3(100R)、R4(100K) — 轴向，不分正负。
2. **二极管** D1(1N5822)、D2(1N4007) — ⚠️ **有正负**：外壳有白圈的一端是**负极**，对照板上丝印/焊盘（负极朝 +12V，即朝 T1/T2 的 + 端）。
3. **IC 座 + ULN2803**(U2) — 先焊 18 脚 IC 座，芯片后插。⚠️ **缺口/圆点对 1 脚**（板上有 1 脚方焊盘）。
4. **瓷片电容** C2/C3(104) — 不分正负。
5. **电解电容** C1(100µF) — ⚠️ **长脚=正极**，插方焊盘（+ 端，朝 +12V）。
6. **AMS1117**(U1) — 唯一的贴片(SOT-223)，也最好焊：先焊一边固定，再焊其余脚和大散热片。
7. **IRLZ44N**(Q1) — TO-220 三脚，⚠️ 别插反（G/D/S 对照板上 1 脚方焊盘）。
8. **接线端子** T1/T2/T3(KF301) — 蓝绿色那种，注意方向（进线口朝板外）。
9. **排针/排母** J1(6P)、J2(4P) — 接杜邦线到 ZYNQ / 接传感器。

**接线（和你原电路图一致）：**
- T1 ←→ 气泵（+ : −）
- T2 ←→ V2 阀（+ : −）
- T3 ←→ 12V/3A 适配器（+ : −，经 DC 母座转接线）
- J1(6P) ←→ ZYNQ ATK 口 6 根杜邦线：**1=SCL 2=SDA 3=泵 4=阀 5=GND 6=+5V**
- J2(4P) ←→ 气压传感器：**VCC / GND / SCL / SDA**（对照你传感器模块的针脚顺序）

## 上电顺序（安全！和原方案一样）

1. **只接 ZYNQ + 驱动板**（不接 12V）：LCD 跑起来，看 Gate/OUT1 电平是否随状态机翻转。
2. **接 12V 空载**（不接泵/阀）：量 T1/T2 输出端电压对不对。
3. **接泵和阀**联调：做 充气→保压→泄气 全流程。
4. ⚠️ **调试期严禁戴在人手上**；V2 必须是**常开(NO)**型，断电自动泄压。

## 万一想改板子

板子是由 `gen_pcb.py` 自动生成的（元件布局、走线都在里面，带中文注释）。
改完重新跑一遍就行（需要装好 Python + KiCad）：

```
py gen_pcb.py            # 重新生成 .epro
< KiCad python > convert_epro.py 医用手套驱动板.epro board.kicad_pcb
kicad-cli pcb drc ...    # 重新验证
```

不懂代码也没关系——直接在立创EDA专业版里打开 .epro 手动改更简单。
